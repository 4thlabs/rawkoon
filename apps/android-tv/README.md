# Rawkoon Android TV

Native Android TV audiobook player for a [Rawkoon](https://samlo.cloud/rawkoon)
server — browse the audiobook library, resume, and listen with
chapter navigation and remote-friendly controls.

See the design spec: `docs/superpowers/specs/2026-09-07-rawkoon-android-tv-audiobook-design.md`.

Standalone repo (not part of the rawkoon monorepo). Playback client only —
Rawkoon does acquisition, this app plays what's in the library.
